


# Log Analyzer CLI Tool

 Overview:

The **Log Analyzer CLI Tool** is a straightforward command-line utility designed to help you analyze server log files efficiently. It simplifies the process of extracting useful information from large log files (such as those generated by web servers like NGINX or Apache), providing key insights like the most accessed URLs, top IP addresses, HTTP status codes, and more.

This tool is ideal for developers, system administrators, and anyone who needs to process log files for troubleshooting, analytics, or performance monitoring directly from the terminal.

---

## Features:

- Request Counting**: Quickly count the total number of requests in the log file.
- **Top URLs**: Identify the most frequently requested URLs.
- **IP Address Analysis**: Find the IP addresses that made the most requests.
- **Status Code Filtering**: Filter log entries by specific HTTP status codes (e.g., 404, 500).
- **Flexible Output**: Display results in a human-readable format or export them in JSON for further processing.


## How It Works:

The tool processes standard server log files and extracts useful information based on various metrics. Once the log file is processed, it outputs a summary of the data you're interested in.

### Example Use Cases:
- **Monitoring Web Traffic**: Quickly get insights into the most popular pages on your website.
- **Troubleshooting Errors**: Identify recurring HTTP errors (such as 404s or 500s) to resolve issues.
- **Security Analysis**: Track suspicious IPs by analyzing request patterns.


## Usage:

Once the tool is installed, you can run it directly from the command line. Simply provide the path to your log file, and the tool will generate an analysis report.

### Example of Running the Tool:

After installing, the basic command looks like this:

```bash
log-analyzer path/to/your/access.log
```

The tool will then process the log file and provide a summary of key information. You can also specify additional parameters to filter or customize the output.

### Options Available:

- **Top URLs**: Show the most requested URLs in the log file.
- **Top IPs**: Display the IP addresses with the most requests.
